# Test corpora

Real-world samples every release is tested against. **Every bug report with a sample becomes a corpus entry.**

| Folder | Target size | Used by |
|---|---|---|
| `equations/` | 500 equations | Math rendering, LaTeX ↔ MathML ↔ OMML conversion |
| `paste/` | 300 clipboard HTML samples from Word, Excel, Google Docs, websites | Paste cleanup |
| `docx/` | 300 Word files | DOCX import/export round-trip |

Only add files you have the right to share (create your own, or use public-domain/permissively licensed documents). Never add personal or confidential documents.
