# @axiomtext/plugin-columns

Column layouts (2 or 3 columns), including **text on both sides** of a centered image
(used by `@axiomtext/plugin-image` when you choose "Text on both sides").

Saved as plain HTML with CSS grid — load `@axiomtext/ui/content.css` on your website and it
renders the same as in the editor; on narrow screens the columns stack.

Part of [AxiomText](https://axiomtext.dev), the free MIT rich text & math editor.
