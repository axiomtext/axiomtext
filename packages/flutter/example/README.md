# AxiomText Flutter example

Four demos: **Notes** (native toolbar above the keyboard, autosave, word count),
**Math homework** (native math keyboard), **Document** (the editor's own toolbar, paper-like page,
HTML/Markdown export) and **Comment box** (an editor that grows inside a scrolling list).
Switch language (10, including Arabic right-to-left) and light/dark from the app bar.

```bash
cd packages/flutter/example
./tool/create_platforms.sh   # once: creates android/ ios/ macos/ web/ and adds permissions
flutter run                  # Android, iOS, macOS or Chrome
```
