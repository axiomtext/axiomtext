title: Keyboard shortcuts
description: Every keyboard shortcut and Markdown trigger.
---

Press <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>/</kbd> in the editor to see these. "Mod" is <kbd>⌘</kbd> on
Mac and <kbd>Ctrl</kbd> elsewhere.

| Action | Keys |
|---|---|
| Bold / Italic / Underline | Mod+B / Mod+I / Mod+U |
| Strikethrough | Mod+Shift+X |
| Inline code | Mod+E |
| Subscript / Superscript | Mod+, / Mod+. |
| Highlight | Mod+Shift+H |
| Link | Mod+K |
| Clear formatting | Mod+\ |
| Paragraph / Heading 1–6 | Mod+Alt+0 / Mod+Alt+1…6 |
| Bulleted / Numbered / To-do list | Mod+Shift+8 / 7 / 9 |
| Quote | Mod+Shift+. |
| Align left / center / right / justify | Mod+Shift+L / E / R / J |
| Indent / Outdent | Mod+] or Tab / Mod+[ or Shift+Tab |
| Line break / Page break | Shift+Enter / Mod+Enter |
| Equation / Block equation | Mod+Shift+M / Mod+Alt+M |
| Edit selected equation | Enter |
| Undo / Redo | Mod+Z / Mod+Shift+Z or Mod+Y |
| Move to the toolbar | Alt+F10 (Esc returns) |
| Move a selected image | Arrow keys after clicking it, or Alt+Shift+arrows |

## Markdown triggers

| Type | Result |
|---|---|
| `# `, `## `, … | Heading |
| `- ` or `* ` | Bulleted list |
| `1. ` | Numbered list |
| `[ ] ` | To-do list |
| `> ` | Quote |
| `---` | Horizontal line |
| `**text**`, `*text*`, `~~text~~`, `` `code` `` | Bold, italic, strikethrough, code |
| `$x^2$`, `\(x^2\)` | Inline equation |
| `$$ ` | Block equation |

Backspace right after a trigger undoes it.
