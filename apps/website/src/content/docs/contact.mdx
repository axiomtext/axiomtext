## Get in touch

Email **[support@axiomtext.dev](mailto:support@axiomtext.dev)** for anything that doesn't fit a
public issue: using AxiomText in your product, partnerships, or a question you'd rather not ask in
public. We usually reply within two working days.

| For | Where |
| --- | --- |
| A bug, or a feature you'd like | [Open an issue on GitHub](https://github.com/axiomtext/axiomtext/issues/new/choose) |
| A question about using AxiomText | [GitHub Discussions](https://github.com/axiomtext/axiomtext/discussions), so others can find the answer too |
| A security problem | [Report it privately](https://github.com/axiomtext/axiomtext/security/advisories/new) or email [security@axiomtext.dev](mailto:security@axiomtext.dev). Please don't open a public issue. See the [security guide](/guides/security/). |
| Anything else | [support@axiomtext.dev](mailto:support@axiomtext.dev) |

When you report a bug, the editor version (`npm ls axiomtext` or the version in `pubspec.yaml`),
your browser or device, and a few steps or a short document that shows the problem help us fix it
quickly.

## Support the project

AxiomText is free under the MIT license, including for commercial use, and every feature stays
free. If it saves you time or money, you can help keep it that way:

- **[Become a patron on Patreon](https://www.patreon.com/axiomtext)**: monthly support pays for development time,
  testing devices and the website.
- **Star [the repository](https://github.com/axiomtext/axiomtext)** and tell other developers
  about it.
- **Contribute**: fixes, translations and documentation are welcome. Start with the
  [contributing guide](https://github.com/axiomtext/axiomtext/blob/main/CONTRIBUTING.md).
